# content/

Reviewed, version-controlled YAML content. Nothing here is generated, and nothing here is
written by the application at runtime.

## What belongs here

Content that a human has reviewed and that the Decision Layer reads as **versioned
configuration**: skill taxonomies, assessment question banks, company and role hiring bars,
band boundaries, weights, and pacing rules for the preparation plan.

Files in this directory are the reviewed source. They are loaded into the database as
versioned rows by a migration or an explicit import step, and the Decision Layer reads them
from there — never from disk at request time. That is what makes `config_version` and
`taxonomy_version` on a scoring run meaningful: a run records exactly which content produced
it, and re-running it later with that version reproduces the same numbers.

## What does not belong here

- Anything generated by a model. Content is reviewed by a person before it lands.
- Anything a user creates. That is application data and lives in PostgreSQL.
- Numbers nobody has verified. A company's hiring bar is a factual claim about that company.
  An invented threshold produces a readiness score that is confidently wrong, which is worse
  than having no score at all.

## Current state

Empty, deliberately. No taxonomy, thresholds or question content has been supplied yet, and
none will be invented to fill the gap. When content arrives it lands here first, gets reviewed,
and only then gets a migration that versions it into the database.
